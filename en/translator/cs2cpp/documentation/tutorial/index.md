# CodePorting.Translator Cs2Cpp Tutorial examples #

This section collects the tutorials. These brief examples demonstrate how to translate specific types of target C# code.

## Base Assumptions ##

All the examples below are based on the following assumptions:

* Translator with framework is installed to *C:\CodePorting.Translator_Cs2Cpp* directory
* The sample C# code (if any) is located in *C:\SampleName* directory, where `SampleName` is the name of example in [GitHub examples repository](https://github.com/codeporting-translator/codeporting-translator-cs2cpp/tree/master/ExampleProjects/).
* The output directory is *C:\output*
